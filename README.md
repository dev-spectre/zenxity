# Zenxity

A "coming soon" landing page for Zenxity — a career discovery platform.

## Overview

A single-page landing page with an email signup form for the Zenxity platform. Features a modern design with animated elements and a CNAME for custom domain deployment.

## Features

- Email signup form with validation
- Responsive design
- Custom domain support (CNAME)
- Modern, animated UI

## Tech Stack

- HTML5, CSS3, Vanilla JavaScript

## Getting Started

Open `index.html` in a browser. Deploy to GitHub Pages or any static host.

## Project Structure

```
├── index.html             # Landing page
├── script.js              # Form handling and animations
├── LICENSE
└── CNAME                  # Custom domain config
```
